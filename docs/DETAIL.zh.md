# 腾讯广告工具

右侧栏的「腾讯广告」面板：八个投放分析工具 + 格里芬取数，全部在面板里直接出结果；
主对话也能通过 `ad_tools_report` / `ad_tools_last_report` 直接取数分析。
左侧栏的「腾讯广告」入口点一下就把面板开到右侧栏；右侧栏「开始」页也有一张「腾讯广告」卡片
（tab 类型 `ad-tools`），直接点卡片或在 tab 条的添加控件里选它都能打开。对话留在中间，
面板在右侧，互不遮挡。

**不再需要先起本地服务。** 面板不是 iframe：Host 半自己跑脚本、自己登录 Grafana，
浏览器端只负责参数和渲染。凭证在面板「设置」里填，不用再去改 `.env.local`。

## 面板长什么样

- 顶部一行：标题、`设置`；
- 第二行：八个工具页签 + `格里芬数据` + `AI 分析`；
- 参数行：日期区间 / 维度（创角次留）/ `含暂停 · 历史单元`（定向监控）/ 账户下拉 / `查询`；
- 正文：KPI 卡片 → 告警 / 口径提示 → 表格（分组、合计、条形、标签、素材缩略）→ 榜单 / 配置快照；
- 表格右上角「复制表格」直接得到可粘进 Excel 的 TSV；周报页脚有「导出周报 Markdown」。
- 切到别的插件再回来，页签、日期、账户和每页的结果都还在，不会重新查询；查询还没返回时就切走，结果也会落到回来后的面板上。只有打开 DSH 后的第一次才自动拉盯盘。

| 页签 | 脚本（插件内置） | 说明 |
| --- | --- | --- |
| 盯盘 | `盯盘.mjs` | 在投单元的成本 / 次留 / 超标 / 告警 |
| 创角次留 | `创角次留.mjs` | 逐日 / 版位 / 素材，错位口径 |
| 注册留存 | `注册留存.mjs` | 注册成本与后台口径次留 |
| 创意数据 | `创意数据.mjs` | 计划 × 创意，含暂停建议与三张榜 |
| 周报 | `周报生成器.mjs` | 四段固定模板，可导出 Markdown |
| 保本出价 | `保本出价.mjs` | 目标人群 LTV 上限 |
| 单元LTV判定 | `单元LTV判定.mjs` | LTV ÷ CAC，加量 / 观察 / 停 |
| 定向监控 | `定向监控.mjs` | 配置 vs 实际人群、变更留痕 |
| 格里芬数据 | — | 六套报表 SQL + 自定义只读 SQL |
| AI 分析 | — | 默认用 DSH 内置模型向面板数据提问，不用配 Key |

## AI 分析

最后一个页签：不用导出、不用贴数据，直接对面板上已经查出来的数据追问。选择数据源
（默认自动取当前工具报告 / 格里芬报表 / 自定义 SQL 结果其中一份），输入自然语言问题即可；
同一次面板会话来回答的上下文会一直带上（最近 20 条）。

- 默认走 DSH 自带的 DeepSeek 模型（`deepseek-flash`，流式、不开推理、最长等 2 分钟），复用
  DSH 自己登记的 DeepSeek 路由，**不用单独配 Key**；页签顶部会标「正在用 DSH 内置的
  DeepSeek 模型」。
- 配了 `DeepSeek API Key` **且**在「设置」里把 `AI 直连地址` 或 `直连模型名` 改成了非默认值时，
  视为明确想用自己的端点：**优先直连** `/chat/completions`（temperature 0.3，非流式），不再走 DSH 内置
  模型——想接本地代理 / 中转 / 自建服务就填这两项。
- 只填了 Key、地址和模型都是默认值时，Key 作回退：DSH 内置模型不可用（缺凭证 / 没路由）才直连
  DeepSeek 官方 `https://api.deepseek.com`（`deepseek-chat`）。两者都没配时页签里提示去「设置」。
- 回答只基于随 system 消息发过去的那份数据快照；格里芬源还会把用到的 SQL 一并带上。
  页签顶部有「数据快照」chip，标明当前给模型看了什么。
- 追问不再重复发数据 —— 快照只发一次，后续轮次引用上文，不用重新查询。
- 既没有 DSH 内置模型、也没配 API Key 时，页签里会给提示框，一键跳到「设置」。
- Key 在「设置」→ `DeepSeek API Key` 里填：同样存进 `~/.dsh/storages/ad-tools/config.json`
  （0600），不写回、不回显，浏览器侧只能看到 `hasDeepseekKey`。

## 主对话取数（不用打开面板）

插件还向 DSH 登记了两个主机工具，主对话里的模型可以直接取数、直接分析：

| 工具 | 作用 |
| --- | --- |
| `ad_tools_report` | 跑某一个投放分析工具（`monitor` / `retention` / `register` / `creatives` / `weekly` / `ceiling` / `units` / `targeting`）；参数与面板一致：`start` / `end` / `dim` / `all` / `account_id` / `max_rows` |
| `ad_tools_last_report` | 读右侧栏最近一次查询的报告全文；用户刚在面板跑过数据、再问「帮我分析一下」时不必重查 |

- 返回的是同一份报告模型降级后的纯文本（KPI、异常、口径提示、表格、成本榜），不是截图，
  也不是另一套口径；`max_rows` 默认每个表格 120 行，超出会明确标注省略。
- 来源行会写清工具、账户、参数和查询时间；凭证始终留在 Host，模型只拿到数字。
- 面板与主对话共享「最近一次报告」：面板查完，主对话可以直接读；主对话查完，也会覆盖这份缓存。
- 这两个工具只在 DSH 提供 `tools` 服务时登记；纯 HTTP 环境（或老版本 DSH）下自动跳过，面板照常可用。

右侧栏负责「看」，主对话负责「问」——分析时不用再把数据复制出去。

## 数据怎么流

```
浏览器面板（client.js）
   │  POST api/ad-tools/{run,griffin/report,ai/chat,...}
   ▼
Host 半（index.js → lib/*.js）
   ├─ 投放分析：spawn <插件>/scripts/<脚本>.mjs --json   ← 随插件安装，不依赖外部目录
   │             stdout 最后一行 JSON → lib/report.js 归一 → 统一报告模型
   ├─ 格里芬：   POST <grafana>/login → /api/ds/query（六套报表 SQL 逐字照搬）
   ├─ 素材预览：dynamic_creatives/get → videos|images/get（10 分钟缓存）
   ├─ AI 分析：  ai/chat 把面板数据序列化成文本 → 配了 Key 且地址/模型非默认时
   │             直连 POST <deepseekApiBase>/chat/completions；否则走 DSH 内置 LLM（deepseek-flash），
   │             只在 DSH 没可用路由且配了 Key 时回退到默认官方直连
   └─ 主对话：   ctx.tools 登记 ad_tools_report / ad_tools_last_report
                 → 同一套 runByKey + normalize → 文本报告（按行数截断）
```

为什么**不**把脚本搬进插件：这些脚本会随平台字段和口径修正不断更新，复制进来就会分叉成
两套数字。插件只负责「凭证 + 参数 + 进程 + 渲染」，目录在设置里可改。

## 凭证

存一份 JSON：`~/.dsh/storages/ad-tools/config.json`（0600）。面板「设置」写入，改完即时生效。

| 项 | 用途 |
| --- | --- |
| `grafanaUrl` / `grafanaUser` / `grafanaPass` | 格里芬登录 |
| `dsMain` / `dsX7` | 两个 Grafana MySQL 数据源 UID |
| `tencentToken` | 腾讯广告 `access_token` |
| `deepseekKey` | DeepSeek API Key（AI 分析直连；配了它 + 自定义地址 / 模型时优先直连，可选） |
| `deepseekApiBase` / `deepseekModel` | AI 直连地址 / 模型名，默认 `https://api.deepseek.com` / `deepseek-chat`；改成非默认值即优先直连 |
| `accountId` | 默认广告账户 ID；**不内置默认值**，首次使用必须填。也是向平台拉账户列表的种子账户 |
| `accountList` | 手动维护的账户列表 `[{ id, name }]`，设置里一行一个（ID + 可选备注）；可选 |
| `adToolsDir` | 旧版遗留：仅在内置脚本缺失时兜底，正常不用改 |

解析顺序逐项独立，先命中先用：

1. 上面这份配置文件（面板设置）；
2. 环境变量 `GRAFANA_URL` / `GRAFANA_USER` / `GRAFANA_PASS` / `MKT_ACCESS_TOKEN` / `MKT_ACCOUNT_ID`；
3. 旧工具的既有位置：`griffin-data-tool/.env.local`、仓库 `tmp/tencentads_credentials.json`。

第 3 条是迁移兼容：老用户不填也能跑，填了就覆盖。插件**只读**这些文件，不复制、不改写，
凭证也不会进插件目录或提交记录。密码 / 令牌永远不回显到浏览器，只看得到「已保存」。
面板里留空 = 不改；要删已存的值，点「清除已存密码 / 令牌」再保存。

### 账户从哪来

参数行的「账户」下拉不是插件里写死的名单，而是三处合并、按 ID 去重：

1. 设置里的**账户列表**（`accountList`，手动填的，永远在；备注名优先于平台工商名）；
2. 设置里的**默认账户** `accountId`；
3. 腾讯广告 `advertiser/get` 查到的账户，带工商名和账户状态；
4. 旧凭证文件里的 `known_accounts`（迁移兼容，只读）。

**注意 `advertiser/get` 不是「列出名下全部账户」**：它必须带一个 `account_id`（空值平台回
`132115 BM账户调该接口时，参数account_id不能为空`），而且直客 token 只返回被查询的那个账户本身。
实测同一 token 查两个不同账户 ID，每次都只回被查的那一个 —— 而这两个账户的
`adgroups/get` 都能跑通，说明 token 有权限、只是没有枚举能力。官方口径也一样：直客必须传
`account_id`、只能查到自己；只有服务商 / 服务商主体 token 才能列名下子客（`agency/get` 会直接回
`132307 此接口仅允许服务商/服务商主体token使用`）。商务管理平台的 `business_manager_relations/get`
对当前 token 返回空列表，`business_mdm_account_relations/get` 的 `RELATION_TYPE_MDM` 报 31009。

所以 `accountId` 是**种子账户**：优先用它去查，没填就拿账户列表的第一个，两处都空才提示「未配置广告账户」。
别的账户要么手动写进账户列表，要么在设置里填 ID 点「查这个账户」——平台上能查到工商名，再把
「加入列表」固定下来。账户列表的用处就是补平台列不出来的账户、起自己的备注名、固定常用几个。

切换下拉后，这一轮查询（含素材预览）就用那个账户；主对话的 `ad_tools_report` 也能通过 `account_id` 按次指定。

**在哪拉、在哪看**：设置里「平台已授权账户」一块。

- 「从平台拉取」查**默认账户**，并把手动列表里的账户逐个查一遍，补上工商名和账户状态；
  列表里显示账户 ID、工商名、状态、来源（默认账户 / 手动列表 / 旧凭证 / 平台授权），
  每行有「加入列表」，点一下固定进上面的手动列表。
- 「查这个账户」：输入任意账户 ID 单独查，用来拉不在默认账户里的号；
  查到后同样可以「加入列表」。
- 参数行账户下拉右边的 `↻` 是同一个接口的快拉按钮，不用每次进设置。

拉取用的是**已保存**的 token 和默认账户，所以换过 token 要先「保存」再拉；平台报错（比如
`12201 account_id 参数无效`）会原样显示在按钮下面。

`deepseekKey` 可选：不配也能用 DSH 内置模型做 AI 分析。它只存在这份配置文件里、只作直连（配了
自定义地址 / 模型时优先），不走环境变量、不读旧工具文件；浏览器侧只能看到 `hasDeepseekKey`，
永远不会回显 Key 本身。

### 两处需要说明的桥

- **凭证重定向**：八个脚本都从 `<仓库>/tmp/tencentads_credentials.json` 读 token，没有环境变量
  兜底。面板里配了 token 时，Host 用 `node --import lib/credfile-shim.mjs` 起子进程，把这次
  读取在内存里换成配置值 —— 脚本一行不改，仓库文件一个字节不动。
- **格里芬 SQL 桥**：`保本出价.mjs` / `单元LTV判定.mjs` 原本通过
  `POST 127.0.0.1:8787/api/sql` 向格里芬服务要游戏侧数据。现在 Host 在跑这两个脚本时临时开一个
  回环口（`127.0.0.1`、系统随机端口、只接受 `POST /api/sql`、只放行 `SELECT` / `WITH` 单条语句），
  把请求接到自己的 Grafana 会话上；跑完 60 秒空闲就关。局域网仍然什么都看不到。

## 安全

- 插件不监听任何对外端口；唯一的监听是上面那个短命回环桥，且只读。
- 所有路由都挂在 DSH 自己的 `connection` 上、仅 POST、仅本机 UI 可达。
- 配置文件 0600；浏览器侧拿到的 `publicConfig` 只有「有没有配」和来源，不含密码 / 令牌原文。
- 素材预览的链接是腾讯广告 CDN 的临时直链，只在点开时现取。
- 插件完全活在 DSH 进程里：关掉 DSH，面板、回环桥和正在跑的脚本一起结束（dispose 时 `killAll()`），不会留下后台服务或孤儿进程；重新打开 DSH 后凭证仍在配置文件里，面板照旧可用。
- AI 分析默认走 DSH 内置的 DeepSeek 模型（用 DSH 登记的 DeepSeek 路由）；配了 Key 且把直连
  地址 / 模型改成非默认值时，数据发往那个自定义端点（默认官方 `api.deepseek.com` 只在 DSH 无
  可用路由但配了 Key 时兜底）。无论哪条路径都只发「数据快照 + 问题 + 对话历史」，
  插件本地不落任何东西、不留存。

## 安装

插件目录：本仓库根目录（克隆到哪里就用哪里）。

在本机 DSH 配置档的 `~/.dsh/profiles/desktop/package.json` 里登记：

```json
{
  "dependencies": {
    "@local/ad-tools": "link:<插件目录绝对路径>"
  },
  "dsh": {
    "profile": {
      "bundles": ["@local/ad-tools"]
    }
  }
}
```

在 profile 目录里建一次 `node_modules/@local/ad-tools` 指向插件目录的 junction，然后重启 DSH，
左侧栏「插件 / 自动化任务 / 上下文洞察」那一列会多出「腾讯广告」入口，点开面板在右侧栏显示
（右侧栏「开始」页也有同一张卡片）。第一次打开先到「设置」里填格里芬地址、账号、密码和腾讯广告 token。

## 排错

| 现象 | 看这里 |
| --- | --- |
| 格里芬页签只提示缺配置 | 设置里补齐地址 / 账号 / 密码，点「测试格里芬连接」 |
| 查询报「找不到脚本」 | 插件安装不完整（`scripts/` 缺文件），或 `AD_TOOLS_SCRIPTS_DIR` 指错了 |
| 报「先启动格里芬」 | 桥没起来：多半是格里芬凭证或网络不通，先点「测试格里芬连接」 |
| 保本出价 / 单元LTV 的平台侧是空的 | 腾讯 token 无效或该窗口没有投放；游戏侧不受影响 |
| 指标全是 0 | 选的窗口没有投放，或账户 ID 不对（设置里切换账户） |
